Investigate the selected or named sprint in the conversation before using page hints. Inspect the Sprint Goal, work mix, ownership, readiness/dependencies and estimation coverage using tools. Explain current focus and concrete next decisions; avoid a preformatted metrics report. Distinguish current status from work completed during the sprint. Ask for dates/history only if the question requires progress through time. Use the owner's workflow/Definition of Done and capacity assumptions. Do not infer blockers, lateness or velocity from a small Done share.

Sprint backlog/remaining work includes all tickets outside CSV Status Category Done, including work still in progress, testing or review as well as To Do. Use sprint_remaining_work to compare/count sprints in one query. Report present unfinished work without claiming historical spillover. A sprint with all tickets in Done has no remaining work; unknown categories prevent asserting full completion.
