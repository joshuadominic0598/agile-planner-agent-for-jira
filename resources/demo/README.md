# AgilePlanner demo export

`agileplanner-demo.csv` contains exactly 100 fictional tickets for **Nimbus Workspace**. It was generated independently; it contains no records, names, attachments or requirements from a private Jira export.

Upload it from the first screen, or choose **Use demo export**. It includes:

- To Do, In Progress, Dev, QA and Prod, with Jira Status Categories.
- Frontend, backend, data engineering, analytics, optimization, DevOps, testing and platform work; stories, tasks, bugs and parent epics.
- Five iterations, story points and time estimates in Jira seconds, including intentionally missing estimates and unassigned work.
- Acceptance criteria, repeated comment/attachment/sprint columns and explicit relationships.

Attachment URLs use `example.invalid`. No attachment bytes are supplied; only the fictional filenames/references can be indexed. Treat Prod as finished to try a release-readiness backlog, or use Status Category Done. Pick a named iteration and define a points/hour budget to test capacity. Use Overview → Manage people to assign fictional members roles and mark active developers; the app does not assume a roster or capacity rule from their names.
